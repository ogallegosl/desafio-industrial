# Guía del estudiante — Desafío Industrial

## 1. Antes de ingresar

Necesitas el código del examen proporcionado por el docente. Para ingresar se solicitarán tus apellidos y nombres.

Utiliza una conexión estable cuando sea posible. La plataforma puede recuperarse de cortes breves, pero una conexión permanente facilita la sincronización de respuestas y evidencias.

## 2. Ingreso

1. Abre la página de acceso del examen.
2. Escribe el código del examen.
3. Completa los datos solicitados.
4. Lee las instrucciones.
5. Pulsa **Iniciar examen** únicamente cuando estés listo.

El tiempo comienza cuando se inicia el intento, no mientras lees la pantalla previa.

## 3. Cronómetro

El tiempo restante se muestra durante todo el examen. El cronómetro usa la hora del servidor; cambiar el reloj del teléfono o computadora no reinicia ni amplía el tiempo.

Si recargas la página o cierras y vuelves a abrir el navegador, el examen conserva el mismo límite de tiempo.


## 4. Uso desde celular

La plataforma intenta mantener la pantalla encendida durante el examen cuando el navegador admite **Screen Wake Lock**. Antes de comenzar:

- carga suficientemente la batería o conecta el equipo;
- desactiva temporalmente el ahorro extremo de energía;
- si tu navegador no mantiene la pantalla activa, aumenta el tiempo de bloqueo automático;
- no cambies de aplicación durante la evaluación;
- mantén el navegador en primer plano.

En celulares no se utiliza la simple pérdida de foco como incidencia porque el teclado virtual y los permisos del sistema pueden generarla. Sí se registra cuando la página deja de estar visible. Un navegador web no puede distinguir siempre entre bloquear manualmente la pantalla y cambiar a otra aplicación.

## 5. Responder preguntas

Según el examen puedes encontrar:

- alternativas;
- selección múltiple;
- verdadero/falso;
- texto corto;
- respuestas numéricas;
- desarrollo;
- imágenes para analizar;
- cálculos;
- fotografías/PDF como evidencia;
- casos con varias subpreguntas.

El sistema muestra el estado de guardado. Una respuesta reciente sustituye a versiones anteriores de esa misma pregunta.

## 6. Internet inestable

Si se pierde temporalmente la conexión, la plataforma conserva respuestas pendientes en el navegador y trata de sincronizarlas cuando vuelve internet.

No borres los datos del navegador, no cambies a otro dispositivo durante un corte y no uses modo incógnito si el docente no lo ha indicado.

Si el tiempo vence durante un corte de conexión, el examen no se extiende. Existe una recuperación técnica limitada para sincronizar respuestas que ya se habían realizado antes del límite.

## 7. Evidencias

Cuando una pregunta solicite evidencia puedes subir, según la configuración docente:

- JPG/JPEG;
- PNG;
- WEBP;
- PDF.

En móviles compatibles puede aparecer la opción para tomar una fotografía directamente. Antes del envío puedes reemplazar o eliminar la evidencia mientras el examen siga abierto.

## 8. Navegación

El docente puede permitir navegación libre o secuencial. En algunos exámenes podrás volver a preguntas anteriores; en otros, esa opción estará desactivada.

## 9. Envío

Antes de entregar, revisa el resumen de preguntas respondidas y omitidas cuando la configuración lo permita. Al confirmar el envío, el intento queda cerrado y ya no podrás modificar respuestas ni evidencias.

Si el tiempo llega a cero, el sistema envía el examen automáticamente.

## 10. Resultados

Lo que veas después del examen depende de la configuración docente. Puede mostrarse:

- solo confirmación de entrega;
- puntaje;
- nota;
- respuestas correctas;
- retroalimentación.

Las respuestas correctas no se publican antes del cierre general del examen. Si el docente programó los resultados para una fecha posterior, podrás volver a consultar con el mismo código e identidad cuando estén disponibles.

## 11. Si aparece un error

No abras varios intentos simultáneos ni pulses repetidamente **Iniciar** o **Enviar**. Si pierdes la conexión, conserva la pestaña y espera a que vuelva internet. Si el problema persiste, informa al docente indicando el mensaje exacto que aparece en pantalla.
