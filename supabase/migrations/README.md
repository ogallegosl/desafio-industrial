# Migrations

Migraciones acumulativas de Supabase/PostgreSQL. Deben aplicarse en orden numérico. La auditoría estricta posterior al Prompt 15 incorpora `0021_strict_audit_fixes.sql`. El Prompt 16 añade `0022_safety_demo_exam.sql` y el Prompt 20 añade `0023_global_settings.sql`; `supabase/sql/bootstrap_all.sql` contiene la secuencia completa para una base nueva.
